# Production notes
Business card canvases are 1050×600 design units, a 3.5×2 inch trim ratio. They are review layouts without bleed; a printer must prepare bleed, safe area, CMYK and proofs. Address and booking wording need owner confirmation before printing. Shirt and window layouts are placement concepts, not manufacturer dielines. Logo vectors are path based, with no embedded raster. Social SVGs and application text remain editable and use system fonts; PNGs lock appearance. Logo was generated with the built-in image tool then color separated and traced into scalable path artwork. Hero was generated with the built-in image tool as conceptual illustration. Original prompts are retained in PROMPTS.md.
