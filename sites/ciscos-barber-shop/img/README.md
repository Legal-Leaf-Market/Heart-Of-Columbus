# Cisco's photo

The arch frame in the hero shows `cisco.webp` from this folder. Until the file
exists the frame shows its placeholder, so the page works either way.

* Use a photo Cisco sends or says we may use. A photo on his Wix site is not
  permission on its own, and the page never loads an image from another server.
* Portrait, about 4 by 5 (800 by 1000 px or larger). The top of the arch is
  round, so keep his head a little below the top edge.
* Save it as WebP named `cisco.webp`, for example
  `cwebp -q 82 photo.jpg -o cisco.webp`.

The build copies this folder to `/preview/ciscos-barber-shop/img/`. This README
stays in the repo.
