# Sticker asset map

The master is a generated 36-sticker PNG sheet. Coordinates are approximate grid locations, not guaranteed cut paths. Some borders approach cell edges. The CSS preview is for art direction; inspect and adjust crop windows before production. Landmark motifs are stylized and should not be labeled as exact architectural depictions. The Indiana drawing is decorative, not a geographic map.
