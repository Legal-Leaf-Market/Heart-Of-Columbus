# Art sources

Vector originals for every PNG in `public/art/`, same names. Edit the SVG,
then export the PNG at the size below and drop it into `public/art/`.

- `cover-<type>.png`: 1600 x 700 banners, shown full bleed across the top of
  business cards and business pages. One per business type (51).
- `cat-*`: 512 x 512. `area-*`: 600 x 600. `float-*`: 800 x 800.
- `empty-*`: 800 x 600. `hero-skyline`: 2400 x 700. `og-image`: 1200 x 630.
- `pattern-*`: 512 x 512 tiles. `map-pin`: 256. `spin-wheel`: 1000.
- `owners-storefront`: 1200 x 900. `keep-local-coins`: 900 x 900.

`og-image`, `keep-local-coins`, `pattern-prairie` and `pattern-tools` are in
the library but not used on a page yet.
